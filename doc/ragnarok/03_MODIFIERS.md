## 1. 3중 분류 체계

RO의 모든 전투 개체는 **속성(Element) × 종족(Race) × 크기(Size)** 세 축으로 분류된다.
장비·카드·스킬은 이 축을 상대로 배율을 건다. 이 체계가 RO 아이템 수집의 엔진이다 —
"만능 장비"가 존재할 수 없고, 사냥터마다 장비를 바꾸게 만든다.

| 축 | 대략적 값 | 성격 |
|----|-----------|------|
| **Element** | 무·수·지·화·풍·독·성·암·염·불사 (각 Lv1~4) | 상성표가 **음수~200%+** 로 요동친다. 가장 강한 축 |
| **Race** | 무형·불사·동물·식물·곤충·어패·악마·인간형·천사·용 | 상성 없음. 카드가 %를 더한다 |
| **Size** | 소형·중형·대형 | 무기 종류마다 크기별 기본 배율이 다르다 |

**속성 상성은 배율이 양방향으로 극단적**이다. 상성이 맞으면 배 이상, 어긋나면
무효·흡수(회복)까지 간다. 레벨(Lv1~4)이 올라갈수록 상성표의 진폭이 커진다.
정확한 표는 [Element](https://irowiki.org/wiki/Element) 원문을 참조한다 (10×10×4).

## 2. 카드가 이 축에 거는 배율

카드([04_ITEMS](04_ITEMS.md) §4)의 표준 수치는 다음과 같이 부위별로 나뉜다.

| 부위 | 효과 | 표준 수치 |
|------|------|-----------|
| 무기 카드 | 특정 **종족** 상대 물리 피해 증가 | +20% (일부 15%) |
| 무기 카드 | 특정 **크기** 상대 물리/마법 피해 증가 | +15% (+ATK/MATK 5 동반하기도) |
| 방패 카드 | 특정 **종족** 상대 받는 피해 감소 | −30% |
| 방패 카드 | 특정 **속성** 상대 받는 피해 감소 / 같은 속성 상대 피해 증가 | −20% / +5% |
| 방패 카드 | 특정 **크기** 상대 받는 피해 감소 | 감소 |
| 갑옷 카드 | 착용자 방어구에 **속성 부여** | 전부 Lv1 |
| 액세서리 카드 | 특정 **종족** 상대 물리 피해 증가 | +5% |

읽는 법: **공격 배율은 무기, 방어 배율은 방패, 속성 정체성은 갑옷**에 붙는다.
부위마다 역할이 고정되어 있어 조합 공간이 폭발하지 않는다.

## 3. 상태이상 (Status Effects)

주요 이상과 그 **행동 봉쇄 범위**:

| 상태 | 봉쇄 범위 |
|------|-----------|
| **Stun** | 이동·공격·스킬·아이템·아이템 줍기·앉기 전부 불가, 강제 해제 불가 |
| **Sleep** | 아무 행동 불가. **공격이 자동 명중**하고 **치명타 확률 2배** |
| **Silence** | 비패시브 스킬 전부 불가 (평타·이동은 가능) |
| **Curse / Blind / Poison / Deadly Poison / Frozen / Stone Curse / Burning / Bleeding** | 각각 스탯 감소·지속 피해·이동 봉쇄 등 부분 효과 |

**저항은 스탯이 담당한다.**

| 스탯 | 저항 대상 |
|------|-----------|
| **VIT** | 기절, 독, 맹독, 화상, 동결 |
| **LUK** | 실명, 저주, 동결, 독, 침묵, 수면, 석화, 기절 |

해제 수단은 스킬(Dispell, Recuperate 등), 아이템, 시간 경과로 나뉘고, 일부 버프는
특정 이상에 대한 **면역**을 준다(예: Battle Chant — 침묵 면역 60초).

설계 포인트: 상태이상이 **확률 판정 + 저항 스탯 + 해제 수단**의 삼각형으로 묶여
있다는 것. 셋 중 하나라도 빠지면 "무조건 걸리는 봉쇄기"나 "아무도 안 쓰는 스킬"이 된다.

## 4. 보스 프로토콜 (Boss Protocol)

MVP·보스 몬스터에 붙는 특수 플래그. 다음이 **전부 무효**다.

- 상태이상 일체 (침묵·기절·독 등)
- 넉백
- 은신(Hiding) 계열 회피 — 보스는 은신을 감지한다

보스전에서 "봉쇄 → 무한 딜"이 성립하지 않게 만드는 장치. 보스가 단순히 HP만 높은
몬스터가 되지 않게 하는 최소 규칙이다.

## OpenMMO 적용

**현재 상태**
- 디버프 시스템이 이미 있다 ([doc/DEBUFF.md](../DEBUFF.md), `data-src/debuffs.csv`):
  `chance`, `durationSecs`, `dps`, `moveMult`, `attackMult`, `carryMult`,
  `drainMult`, `blocksRegen`. 현재 식중독·출혈 2종.
  같은 디버프는 중첩 대신 시간 갱신, 다른 디버프는 **배수 곱연산**.
- 몬스터에 `material`(flesh/leather 등)이 있으나 이는 타격음·연출용이고
  데미지 배율 축이 아니다. `hitDebuff`로 피격 시 디버프 부여는 가능하다.
- 속성/종족/크기 배율 축은 **없다**.

**가져올 것**
1. **저항 스탯의 도입.** 지금 `chance`는 고정 확률이다. RO처럼 방어자 스탯이
   확률을 깎게 만들면(예: CON→독/출혈, WIS→정신계) 디버프가 밸런싱 가능한
   시스템이 된다. `debuffs.csv`에 `resistStat` 컬럼 하나 추가로 시작할 수 있다 —
   **비용 대비 효과가 가장 좋은 항목**.
2. **보스 프로토콜.** `monsters.csv`에 이미 `boss` 컬럼이 있다. 여기에
   "디버프·넉백 면역"을 묶으면 보스전 설계가 즉시 단단해진다. 코드 변경 최소.
3. **크기 축 하나만** (소/중/대). 3축 전부는 과하지만, 무기 종류별 크기 배율은
   "둔기는 대형에, 단검은 소형에" 같은 무기 선택 이유를 만든다. 이미
   `items.csv`에 `dice`·`material`·`category`가 있어 컬럼 하나로 붙는다.

**변형할 것**
- 속성 상성 10×10×4는 OpenMMO의 D&D 톤과 물량 모두에 과하다. 대신 **저항/취약
  태그** 수준으로 축소한다: 몬스터가 `resist`/`weak` 태그를 갖고, 해당 데미지
  타입에 ×0.5 / ×1.5. 카드가 없으므로 무기 인챈트와 소비 아이템으로 대응.
- 상태이상 목록: RO의 12종을 그대로 옮기지 말고, OpenMMO에 이미 있는 2종에
  **기절(행동 봉쇄) · 침묵(스킬 봉쇄) · 실명(명중 감소)** 3종을 더하는 선에서 멈춘다.
  스킬 시스템이 없는 상태에서 침묵은 무의미하므로 스킬 도입과 함께 넣는다.

**기각할 것**
- 종족 축(10종). OpenMMO 몬스터 수가 RO의 1/100 규모라 분류축을 더 만들면 각 칸이
  비어 버린다. 크기 축 하나로 충분하다.
- 카드 시스템 전체 ([04_ITEMS](04_ITEMS.md) §4에서 별도 판단).
